# Contributing to DoryAI

Thanks for helping improve DoryAI. Open an issue before a large change so we can agree on its scope. For a focused pull request, keep the change in the owning app, add tests for behavior changes, and run `npm run check` from the repository root.

Do not submit credentials, user data, or copied content that you do not have permission to publish. See the app READMEs for local setup and [SECURITY.md](SECURITY.md) for private vulnerability reporting.
